# ADR-001: starter de Semana 1 con concurrencia deliberadamente no resuelta

## Estado

Aceptado.

## Contexto

El proyecto debe servir como starter didáctico para estudiar arquitectura, trazabilidad y una condición de carrera antes de resolverla.

## Decisión

Se mantendrá un alcance pequeño y verificable para la Semana 1. La regla RET-001 se expresará explícitamente, pero la condición de carrera no se resolverá todavía.

## Consecuencias

- La implementación inicial puede mostrar un comportamiento no determinista bajo concurrencia.
- La suite normal debe seguir en verde.
- La prueba `race_demo` se ejecutará por separado para mostrar el defecto pendiente.
